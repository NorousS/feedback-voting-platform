# MVP платформы отзывов и голосований

## 1. Цель MVP

Продемонстрировать базовую цепочку: пользователь открывает список опросов, выбирает вариант ответа, отправляет голос и просматривает результаты. Дополнительно доступна форма текстового отзыва и создание простого опроса.

## 2. Use case UC-01 «Проголосовать в опросе и увидеть результат»

**Актор:** посетитель платформы (без авторизации).

**Предусловия:** запущены frontend и API, в системе есть хотя бы один опрос минимум с двумя вариантами.

**Основной сценарий:**

1. Посетитель открывает страницу `/surveys`.
2. Выбирает интересующий опрос из списка.
3. Система открывает `/surveys/:surveyId` с вопросом и вариантами.
4. Посетитель отмечает один вариант.
5. Нажимает «Проголосовать».
6. Клиент посылает запрос `POST /api/surveys/:id/votes`.
7. Сервер увеличивает счётчик выбранного варианта.
8. Клиент открывает `/surveys/:surveyId/results`.
9. Посетитель видит количество голосов и проценты по вариантам.

**Результат:** голос принят, агрегированные результаты отображены с диаграммами.

**Альтернативные сценарии:**

- Вариант не выбран — интерфейс просит выбрать вариант, запрос не отправляется.
- Опрос отсутствует — сервер возвращает 404, интерфейс показывает сообщение.
- API недоступен — интерфейс показывает сообщение об ошибке.

## 3. Дополнительный use case UC-02 «Отправить отзыв»

**Актор:** посетитель.

**Предусловия:** доступна форма `/feedback`.

**Сценарий:** посетитель открывает форму, вводит текст, необязательно имя и нажимает «Отправить отзыв». Сервер сохраняет отзыв в памяти процесса, интерфейс показывает подтверждение.

**Результат:** отзыв принят сервером.

**Альтернатива:** пустой текст не отправляется, появляется сообщение об ошибке.

## 4. Границы MVP

**Входит в первую версию:**

- React 19 интерфейс в `frontend/` с навигацией;
- список опросов, детальная страница опроса и голосование;
- простая аналитика: число голосов, проценты и диаграммы;
- создание опроса с несколькими вариантами;
- текстовые отзывы;
- библиотека общих UI-компонентов `ui-library/` и её тесты;
- Node.js HTTP API в `../../Downloads/feedback-voting-platform 2/backend` с временными данными.

**Не входит в первую версию:**

- регистрация, авторизация и роли;
- постоянная база данных и миграции;
- защита от повторного голосования и продвинутый антифрод;
- экспорт, фильтры и расширенная аналитика;
- модерация отзывов, уведомления, платёжные функции;
- полноценные нагрузочные и интеграционные испытания.

## 5. Критерии готовности каркаса

- Каждая заявленная страница открывается по прямой ссылке и через навигацию.
- React-приложение импортирует компоненты из `@feedback/ui`.
- `npm run build`, `npm run lint`, `npm run test` успешно завершаются.
- Для `Button` тестовое покрытие не ниже 70% по statements/branches/functions/lines.
- Запросы к API позволяют выполнить основной use case.
- В README представлены реальные скриншоты после локального запуска (добавляются перед сдачей).
